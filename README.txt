MI PATRIMONIO v2

Incluye:
- Acciones con cotización automática.
- Ganancia/pérdida respecto al coste introducido.
- Depósitos y cuentas.
- Conversión de monedas.
- Histórico diario del patrimonio.
- Gráfico de evolución 30/90/365 días.
- Distribución por tipo de activo.
- Copia de seguridad JSON.

Uso:
1) Aloja la carpeta en HTTPS (GitHub Pages, Netlify, etc.).
2) Abre index.html en Chrome Android y añade a pantalla de inicio.
3) Configuración > introduce la API key de Twelve Data.
4) Añade tus posiciones.
5) Pulsa Actualizar.

Nota: una PWA no puede garantizar una tarea diaria en segundo plano cuando el sistema Android la ha cerrado. Al abrirla puede actualizar automáticamente.
